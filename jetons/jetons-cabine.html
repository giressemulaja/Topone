Jetons Cabine de Charge

Chaque jeton a un numéro, un code secret et un motif uniques, calculés à partir du mot secret de la cabine. Le talon de même numéro reste collé au téléphone.

Réglages

Seul le responsable le connaît. Sans lui, impossible de fabriquer un faux code valide.
Changez de couleur et de série à chaque nouveau lot : un ancien jeton se repère tout de suite.
8 jetons par feuille A4. Imprimez en couleur, à 100 % (sans « ajuster à la page »), puis découpez le long des pointillés.
Aperçu à l'échelle réelle

Vérifier un jeton présenté par un client

Saisissez la série, le numéro et le code imprimés sur le jeton. Le mot secret utilisé est celui des réglages.

Le code peut être juste et le jeton faux s'il a été photocopié. Vérifiez aussi que le talon collé sur le téléphone porte le même numéro, le même code et le même motif, et que votre cachet ou signature est bien sur le jeton.

Comment ça marche

Le jeton (6 × 6 cm) est remis au propriétaire du téléphone.
  • Numéro et série
  • Code secret de 5 caractères
  • Motif unique
  • Micro-texte sur le contour
  • Place pour le cachet
Le talon (3 × 6 cm) reste collé au dos du téléphone, avec du scotch ou un élastique.
  • Même numéro, même code, même motif
  • Modèle du téléphone
  • Nom du client, heure de dépôt

Au dépôt

  1. Prenez le prochain jeton de la planche. Notez la date et l'heure sur le jeton et sur le talon.
  2. Sur le talon, écrivez le modèle et la couleur du téléphone (ex. « Tecno Spark 10, bleu »), et le prénom du client.
  3. Apposez votre cachet ou signature dans le rond du jeton. Une photocopie couleur ne reproduit pas un tampon frais.
  4. Collez le talon sur le téléphone. Donnez le jeton au client.

Au retrait

  1. Le client présente son jeton. Vérifiez la couleur et la série du lot en cours.
  2. Retrouvez le téléphone dont le talon porte le même numéro. Comparez le code et le motif : ils doivent être identiques.
  3. Vérifiez votre cachet ou signature sur le jeton. En cas de doute, contrôlez le code dans l'onglet « Vérifier un jeton ».
  4. Rendez le téléphone. Gardez le jeton et le talon (ou déchirez-les) pour qu'ils ne servent jamais deux fois.
Jeton perdu ? Ne rendez le téléphone qu'après une pièce d'identité et la preuve que le client peut le déverrouiller (code ou empreinte). Notez son nom sur le talon.
Pourquoi c'est difficile à falsifier : le code et le motif sont calculés à partir du mot secret, donc un faussaire ne peut pas deviner ceux d'un numéro qu'il n'a pas vu. Le cachet frais, la couleur du lot et le micro-texte rendent la photocopie visible. Et le talon sur le téléphone sert de preuve de référence.
