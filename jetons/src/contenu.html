Jetons Cabine de Charge

Chaque jeton a un numéro, un code secret et un motif uniques, calculés à partir du mot secret de la cabine. Le talon de même numéro reste collé au téléphone.

Réglages

Seul le responsable le connaît. Sans lui, impossible de fabriquer un faux code valide.
Changez de couleur et de série à chaque nouveau lot : un ancien jeton se repère tout de suite.

    Aperçu à l'échelle réelle

    Vérifier un jeton présenté par un client

    Saisissez la série, le numéro et le code imprimés sur le jeton. Le mot secret utilisé est celui des réglages.

    Le code peut être juste et le jeton faux s'il a été photocopié. Vérifiez aussi que le talon collé sur le téléphone porte le même numéro, le même code et le même motif, et que votre cachet ou signature est bien sur le jeton.

    Comment ça marche

    Le jeton (6 × 6 cm) est remis au propriétaire du téléphone.
    • Numéro et série
    • Code secret de 5 caractères
    • Motif unique
    • QR code à scanner avec l'application Registre
    • Micro-texte sur le contour
    • Place pour le cachet sec ou la signature
    Le talon (3 × 6 cm) reste collé au dos du téléphone, avec du scotch ou un élastique.
    • Même numéro, même code, même motif
    • Modèle du téléphone
    • Nom du client, heure de dépôt

    Au dépôt

    1. Prenez le prochain jeton. Dans l'application Registre, scannez son QR code (ou tapez le numéro et le code), puis photographiez le téléphone et enregistrez son modèle et le code de retrait choisi par le client (4 chiffres, par exemple la fin de son numéro). Ce code n'est écrit nulle part sur le jeton.
    2. Notez la date et l'heure sur le jeton et sur le talon.
    3. Sur le talon, écrivez le modèle et la couleur du téléphone (ex. « Tecno Spark 10, bleu »), et le prénom du client.
    4. Pressez votre cachet sec (pince à gaufrer) ou signez au stylo dans le rond du jeton. Une photocopie ne reproduit pas le relief.
    5. Collez le talon sur le téléphone. Donnez le jeton au client.

    Au retrait

    1. Le client présente son jeton. Touchez le relief du cachet sec et vérifiez la couleur et la série du lot.
    2. Scannez le QR dans le Registre. L'application dit si le jeton est faux, déjà rendu ou en dépôt. S'il est valide, elle affiche la photo prise au dépôt : retrouvez ce téléphone.
    3. Demandez au client son code de retrait et tapez-le. Sans le bon code : demandez-lui de déverrouiller le téléphone devant vous.
    4. Vérifiez que le talon du téléphone porte le même numéro, code et motif. Rendez le téléphone : le Registre marque le jeton « rendu ». Gardez le jeton.
    Jeton perdu ? Ne rendez le téléphone qu'après une pièce d'identité et la preuve que le client peut le déverrouiller (code ou empreinte). Notez son nom sur le talon.
    Pourquoi un faux ne passe pas : un jeton inventé n'a pas le bon code (il dépend du mot secret). Une copie d'un jeton déjà utilisé est marquée « rendu » dans le Registre. Une copie parfaite présentée avant le vrai client échoue au code de retrait, qui n'est pas imprimé. Le cachet sec en relief rend en plus toute photocopie visible au toucher.
